							 
			ЗАПУСК БОТА

  	1     cd путь к папке
  	2     py -m pip install -r requirements.txt
  	3     py bot.py - старт бота
		4     Ctrl + C   - остановка бота



		 	Установка Python 3 14 6

		1. Перейдите на официальный сайт: https://www.python.org/downloads/release/python-3146/
		2. Скачайте и установите Python.
		3. При установке Windows обязательно отметьте **Add Python to PATH**.
		4. Завершите установку.
		5. Проверьте, что Python установлен. Откройте PowerShell и выполните:     py --version
		Если команда показывает версию Python, переходите к следующему шагу.

		Расположение файла

		Скачайте или скопируйте файлы проекта в отдельную папку. 
		Например:
		telegram_recipe_bot
		├── bot.py
		├── requirements.txt
		└── recipes.db

			База данных

		Файл `recipes.db` может отсутствовать при первом запуске: программа создаст базу данных автоматически.
		Если в проекте уже есть база данных с рецептами, сохраните её, чтобы не потерять данные.
		Откройте PowerShell в папке проекта.
		Перейдите в папку с кодом, например:
		py -m pip install -r requirements.txt

			Библиотеки

		Если файла `requirements.txt` нет, создайте его и добавьте:
		aiogram>=3.7,<4.0
		Затем выполните установку ещё раз.
